# Books‑Online — Front‑End UI/UX Bookstore Prototype
HTML • CSS • JavaScript — Responsive Multi‑Section Bookstore Interface  
Live Demo: https://lavinia-81.github.io/Books-0nline/

Books‑Online is a front‑end prototype of an online bookstore, created as a learning project to explore UI/UX design, responsive layouts, component styling, and basic JavaScript interactivity.
The project includes multiple sections such as Home, Featured Books, New Arrivals, Reviews, and Blog — each designed to practice different styling techniques and layout patterns.

Although minimal, this project demonstrates early front‑end development skills and experimentation with modern web design concepts.

---

## Overview
Books‑Online is a static front‑end interface built with HTML, CSS, and JavaScript, focusing on:
- clean and structured layout
- responsive design
- styled components
- interactive elements (search bar, navigation, cart icon)
- multi‑section page architecture

This project served as a sandbox for experimenting with styling, spacing, typography, color palettes, and interactive UI behaviors.

---

## Features
### Multi‑Section Layout
- Header — Logo, search bar, navigation menu
- Home Section — Hero banner with promotional content
- Featured Books — Highlighted book cards with images and prices
- New Arrivals — Latest additions displayed in a grid layout
- Reviews — Customer testimonials with styled cards
- Blog Section — Reading‑related articles and updates

### UI/UX Styling
- Responsive grid layouts
- Hover effects
- Styled buttons and call‑to‑action elements
- Typography and spacing experiments
- Color palette exploration

### JavaScript Interactivity
- Search bar functionality
- Navigation menu interactions
- Basic dynamic elements (e.g., cart icon behavior)

A simple, clean structure ideal for practicing front‑end design and layout techniques.

## How to Use
- Open index.html in your browser.
- Navigate through the sections using the header menu.
- Use the search bar to filter book titles (basic functionality).
- Explore featured books, new arrivals, reviews, and blog posts.
